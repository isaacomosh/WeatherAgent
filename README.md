# WeatherAgent
Is an intelligent Python-based weather assistant that provides real-time meteorollogical insights, forecasts and location-aware data through automated tooling.

##Features
Real-Time Weather Retrieval: Instantly fetches current weather conditions, temperature metrics, humidity, and atmospheric data using the OpenWeather API.

Location Intelligence: Integrates with Google Cloud / Maps APIs to resolve locations, coordinates, and targeted geographic points.

Automated Agent Architecture: Built to handle user queries dynamically, parsing requests and returning structured weather updates.

Secure Configuration: Environment-based credential management via .env to protect sensitive API keys.
